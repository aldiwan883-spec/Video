# 18 — Cap Tables

## 1. المصطلح

**Cap table — Capitalization table (جدول الملكية):** جدول بيقول مين يملك إيه في الشركة، وبكام سهم، وبنسبة كام.

## 2. التعريف الدقيق

الـ Cap table بيسجّل كل الأوراق المالية اللي الشركة أصدرتها أو وعدت بيها: أسهم عادية، أسهم ممتازة، Options، Warrants، وأدوات قابلة للتحويل زي SAFEs والـ Convertible notes (شوف [19-convertible-notes-safes.md](19-convertible-notes-safes.md)). وبيوضح نسبة كل حد وإزاي النسب دي بتتغير مع كل جولة (Dilution، شوف [06-equity-dilution.md](06-equity-dilution.md)).

فيه طريقتين لعدّ الأسهم:
- **Basic / Issued and outstanding:** الأسهم المُصدرة فعلاً بس.
- **Fully diluted:** الأسهم المُصدرة + كل الـ options الممنوحة + **الـ option pool غير الممنوح** + أي أوراق ممكن تتحول لأسهم. يعني "لو كل حاجة اتحولت لأسهم، مين هيملك كام؟"

**Option pool (ESOP):** أسهم محجوزة للموظفين الحاليين والجداد. الجزء "غير الممنوح" (unissued) ملوش صاحب لسه، لكنه بيتحسب في الـ fully diluted. والمستثمرين غالباً بيطلبوا الـ pool يتكبّر **قبل** دخولهم، يعني جوه الـ pre-money، فالـ dilution بتاعته بتقع على المؤسسين.

## 3. المعادلة

- `Fully diluted shares = الأسهم المُصدرة + الـ options الممنوحة + الـ pool غير الممنوح + الأسهم الناتجة عن تحويل أي أوراق قابلة للتحويل`
- `نسبة الملكية (FD) = أسهم الشخص ÷ Fully diluted shares`
- `سعر السهم في الجولة = Pre-money valuation ÷ Fully diluted shares قبل الجولة` (شوف [05-pre-post-money.md](05-pre-post-money.md))
- `Post-money = Pre-money + الاستثمار الجديد`

## 4. مثال عملي (افتراضي)

**الوضع الحالي:**
- مؤسس (أ) معاه 6,000,000 سهم، ومؤسس (ب) معاه 3,000,000 سهم
- Options ممنوحة لموظفين = 400,000، وPool غير ممنوح = 600,000

**الحساب:**
1. Fully diluted = 6M + 3M + 0.4M + 0.6M = **10,000,000 سهم**
2. نسبة (أ) Basic = 6M ÷ 9M = **66.7%**، أما Fully diluted = 6M ÷ 10M = **60%**

**جولة جديدة:** مستثمر هيحط 10 مليون جنيه على Pre-money بـ 40 مليون جنيه (Post-money = 50 مليون، يعني المستثمر هياخد 20%). وشرطه إن الـ pool غير الممنوح يبقى **10% بعد الجولة**، والزيادة دي تتحسب جوه الـ pre-money.

3. الأسهم الموجودة اللي مش pool = 6M + 3M + 0.4M = 9.4M، ودول لازم يبقوا 100% − 20% − 10% = **70%** من الإجمالي بعد الجولة
4. إجمالي الأسهم بعد الجولة = 9,400,000 ÷ 0.70 = **13,428,571 سهم**
5. أسهم المستثمر = 20% = 2,685,714، والـ pool بعد الجولة = 10% = 1,342,857، يعني زيادة **742,857 سهم**
6. سعر السهم = 40,000,000 ÷ (13,428,571 − 2,685,714) = 40,000,000 ÷ 10,742,857 = **3.7234 جنيه**
7. للتأكيد: 2,685,714 × 3.7234 ≈ 10,000,000 جنيه ✓
8. نسبة (أ) بعد الجولة = 6M ÷ 13,428,571 = **44.7%**

**الفكرة المخفية (Option pool shuffle):** قيمة زيادة الـ pool = 742,857 × 3.7234 ≈ 2.77 مليون جنيه. يعني الـ Pre-money "الفعلي" اللي المؤسسين والموظفين الحاليين أخدوه = 40 − 2.77 ≈ **37.2 مليون**، مش 40. الـ headline واحد، لكن الحجم الفعلي للـ pool غيّر السعر الحقيقي.

## 5. حدود المفهوم

- النسبة مش هي القيمة. الأسهم الممتازة ممكن يكون ليها **Liquidation preference**، فعند البيع مش كل سهم بياخد نفس المبلغ.
- الـ Fully diluted تعريفه بيختلف من عقد لعقد (هل بيشمل SAFEs؟ وهل بيشمل زيادة الـ pool؟). لازم تقرا التعريف في الورق.
- الـ Cap table صورة للحظة. الـ Vesting والـ options اللي بتنتهي بتغيّره مع الوقت.

## 6. أخطاء شائعة

- إنك تحسب نسبتك على الـ **Basic** وتفرح، وتنسى الـ pool والـ SAFEs.
- إنك تفتكر إن الـ pool غير الممنوح "مش بتاع حد" فمش بيأثر عليك. هو بيأثر على نسبتك من دلوقتي.
- وعود شفهية بأسهم ("هديك 2%") من غير ما تتكتب. ودي من أشهر الـ red flags في الـ due diligence (شوف [17-due-diligence.md](17-due-diligence.md)).
- إنك تدير الـ Cap table على Excel من غير مراجعة قانونية. في مصر وفي الشركات القابضة برا، الملكية القانونية بيحددها السجل الرسمي والعقود، مش الشيت.

## 8. سؤال تفكير

مستثمر عرض عليك Pre-money بـ 40 مليون مع Pool بعد الجولة 15%. والتاني عرض 37 مليون مع Pool 5%، والـ pool الحالي عندك يكفي خطة التوظيف لـ 18 شهر. أنهي عرض أحسن؟

**الإجابة:** غالباً التاني يكون أحسن، رغم إن الرقم أقل. الـ pool الكبير جوه الـ pre-money بيقلل السعر الفعلي اللي إنت بتاخده، وزي ما شفنا في المثال إن pool 10% بس نزّل الـ 40 لـ 37.2 فعلياً. الحكم هنا مش "أنهي رقم أكبر"، الحكم هو **قد إيه pool محتاجه فعلاً** حسب خطة توظيف حقيقية. ولو الـ pool أكبر من احتياجك، فده جزء من التقييم بتديه للمستثمر من غير ما تاخد مقابله.
